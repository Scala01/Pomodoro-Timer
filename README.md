# Pomodoro Timer

A simple and intuitive **Pomodoro Timer** application based on the **Pomodoro Technique**, designed to help improve focus and productivity by alternating work sessions and breaks.

This project is built as a learning exercise following the roadmap.sh Pomodoro Timer project.

## Introduction

The Pomodoro Technique is a time management method that uses a timer to break work into intervals, traditionally 25 minutes in length, separated by short breaks. After completing a certain number of work sessions, a longer break is taken.

This project aims to implement a fully functional Pomodoro Timer with configurable durations and a clean user interface.

## Features

- Start, pause, and reset the timer
- Customizable session durations:
  - Work session (default: 25 minutes)
  - Short break (default: 5 minutes)
  - Long break after 4 work sessions (default: 15 minutes)
- Automatic switching between work and break sessions
- Display of the current session type (Work / Short Break / Long Break)
- Counter for completed work sessions
- Optional sound notification when a session ends
- Responsive design for desktop and mobile devices
